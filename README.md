# 🏠 3D Scene Search with VoteNet + CLIP

3D 포인트 클라우드에서 객체를 탐지하고,
텍스트 쿼리를 통해 원하는 물체를 검색 및 시각화하는 시스템입니다.

------------------------------------------------------------------------

## 🚀 주요 기능

-   3D 객체 탐지 (VoteNet)
-   텍스트 기반 객체 검색 (CLIP)
-   웹 기반 3D 시각화 (Viser)
-   방 내부 시점 카메라 자동 설정
-   맵(Scene) 교체 기능

------------------------------------------------------------------------

## 📂 파일 구조

├── query_3d.py \# 콘솔 기반 3D 검색 테스트 
├── viser_app.py \# 웹기반 3D 시각화 앱 
└── demo_files/ 
└── input_pc_hm3d.ply

------------------------------------------------------------------------

## ⚙️ 실행 방법

### 1. 콘솔 테스트

python query_3d.py

-   탐지된 객체 목록 출력
-   텍스트 쿼리 결과 출력

------------------------------------------------------------------------

### 2. 3D 웹 앱 실행

python viser_app.py


------------------------------------------------------------------------

## 🖥️ 사용 방법 (Viser UI)

-   텍스트 입력 → 객체 검색
-   "전체 물체 보기" → 모든 bbox 표시
-   "방 중앙 시점으로 이동" → 카메라 리셋
-   Scene 선택 → 다른 맵 로드

------------------------------------------------------------------------

## 📥 데이터 형식

입력 데이터는 `.ply` 포인트 클라우드 형식이어야 합니다.

x, y, z, red, green, blue

------------------------------------------------------------------------

## ⚠️ 제한 사항

-   탐지 가능한 클래스는 ScanNet 기준으로 제한됨
-   (bed, chair, door, window, table 등)
-   새로운 객체 탐지는 불가능
