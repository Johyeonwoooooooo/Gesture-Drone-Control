# 3D 공간에서 드론(DJI Tello) 자율주행 프로젝트

## 프로젝트 개요

사용자의 자연어 명령을 받아 DJI Tello 드론이 3D 공간을 이해하고 자율적으로 이동하여 임무를 수행하는 시스템.

**예시 시나리오**: "옆 방에 있는 TV 사진 찍어와줘" → 드론이 자율적으로 옆 방까지 이동 → TV를 찾아 촬영 → 복귀

---

## 시스템 파이프라인

```
[자연어 입력] → [LLM 의도 파싱 / 툴콜링] → [3D Segmentation 좌표 파악]
                                               ↓
                  [드론 이동 실행]  ←  [경로 계획 (A* 등)]
```

---

## 1. 자연어 입력 (User Input)

- 사용자가 자연어로 드론에게 임무를 지시
- 입력 예시
  - "옆 방에 있는 TV 사진 찍어와줘"
  - "거실 소파 위에 누가 있는지 확인해줘"
  - "주방으로 가서 냉장고 앞에서 멈춰"

## 2. LLM 의도 파싱 및 툴콜링 (Intent Parsing)

- LLM이 자연어 명령을 구조화된 태스크로 분해
- 태스크에 필요한 툴(tool)을 선택하여 호출
- 파싱 결과 예시
  - **목표 객체**: TV
  - **목표 위치**: 옆 방
  - **수행 액션**: 사진 촬영
  - **추가 동작**: 복귀

## 3. 3D Segmentation (좌표 파악)

- 사전에 구축된 3D 씬(scene)에서 목표 객체의 위치를 식별
- 현재 [3D-segmentation/](../3D-segmentation/) 모듈과 [Mosaic3D/](../Mosaic3D/) 기반으로 구현 중
- 점별 CLIP 히트맵 → 공간 클러스터링으로 **여러 후보**를 추출, 자세한 내용은 [clustering-candidates.md](clustering-candidates.md) 참고
- 출력: 목표 객체의 3D 좌표 후보 리스트 (rank, center, bbox, score)

## 4. 경로 계획 (Path Planning)

- 현재 위치 → 목표 좌표까지의 안전한 경로 산출
- **알고리즘 후보** (미정)
  - A* (Grid 기반)
  - RRT / RRT*
  - 기타 sampling-based planner
- 결정 시 고려 요소
  - 3D 공간에서의 장애물 회피
  - 드론 동역학 제약
  - 실시간성

## 5. 드론 이동 실행 (Execution)

- 계획된 경로를 DJI Tello가 수행할 수 있는 명령 시퀀스로 변환
- 이동 중 실시간 피드백 처리 여부는 추가 논의 필요
