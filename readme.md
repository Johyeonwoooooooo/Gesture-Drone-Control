# [26-01] 프로메테우스 10팀

## ✋ Gesture Drone Control 🚁

---

## 💡 프로젝트 개요

---

사용자의 **손 제스처 및 자연어 명령**을 인식하여 드론을 직관적으로 제어하는 **비접촉식 인터랙션 기반 드론 제어 시스템**입니다.

카메라를 통해 입력된 손동작을 실시간으로 인식하고, 해당 제스처를 드론 비행 명령어(상승, 하강, 좌우 이동 등)로 매핑하여 **DJI Tello** 드론을 원격 조종합니다.

추후 확장을 통해 **음성(STT) 및 자연어 명령(LLM 기반 해석)**까지 통합하여, 손동작 + 음성 기반의 멀티모달 드론 제어 시스템으로 발전시키는 것을 목표로 합니다.

---

## 🎯 핵심 기능

---

### ✋ 1️⃣ 제스처 기반 드론 제어

- 카메라 입력을 통한 실시간 손 인식
- **MediaPipe** 기반 Hand Landmark 추출
- 특정 제스처와 드론 명령 매핑
    - ✋ 손 위로 올리기 → 상승
    - 👇 손 아래로 내리기 → 하강
    - 👉 오른쪽 가리키기 → 우측 이동
    - 👈 왼쪽 가리키기 → 좌측 이동
    - ✊ 주먹 쥐기 → 정지

---

### 🧠 2️⃣ 제스처 판별 모델 파이프라인

- Landmark 기반 Feature Vector 추출
- Rule-based 또는 간단한 Classification 모델 적용
- 실시간 추론 후 명령어 생성

---

### 🚁 3️⃣ 드론 명령어 전송

- Python 기반 Tello SDK 사용
- 제스처 → Tello 명령어 매핑
- Wi-Fi 기반 실시간 제어

예시 파이프라인:

> 사용자 손동작 → 카메라 입력 → Landmark 추출 → 제스처 판별 → 명령어 변환 → 드론 제어
> 

---

### 🎤 4️⃣ (확장) 음성 + 자연어 기반 제어

- STT(Speech-To-Text) 기반 음성 명령 인식
- LLM을 활용한 자연어 명령 해석
    - "조금만 위로 올려줘" → 상승 속도 낮게
    - "천천히 앞으로 가" → 저속 전진
- 멀티모달 제어 (Gesture + Voice Hybrid)

---

## 🔬 기술 스택

---

**`# Computer Vision`  `# Drone Control`  `# Real-time Inference`  `# Physical AI`  `# LLM (확장)`  `# STT (확장)`**

- **CV**: OpenCV, MediaPipe
- **Gesture Recognition**: Landmark 기반 Rule/ML 분류
- **Drone**: DJI Tello SDK (Python)
- **확장 기술**: Whisper(STT), LLM 기반 명령 해석

## 🌟 차별화 포인트

---

### ✅ 1️⃣ 직관적인 비접촉 제어

리모컨 없이 손동작만으로 드론을 제어하는 **자연스러운 인터페이스** 제공

### ✅ 2️⃣ 멀티모달 확장 가능성

단순 제스처 인식에서 끝나지 않고,

**Gesture + Voice + LLM 기반 지능형 제어 시스템**으로 확장 가능

### ✅ 3️⃣ Physical AI 구현 사례

AI 모델의 추론 결과가 실제 물리 장치(드론)의 움직임으로 연결되는 **End-to-End Physical AI 파이프라인** 구현

### ✅ 4️⃣ 실시간성 중심 설계

Low Latency 추론 구조 설계로 안정적인 비행 제어
